# M3.2-B.2 P1 — Scoped product ingestion API for MeoScout

- **Status:** Implemented locally (2026-11-09); **awaiting approval** before P2 (MeoScout
  relay). Not deployed, not pushed. Design: MeoScout
  `docs/milestones/M3.2-B.2-affilio-direct-integration-design.md`; decision: ADR 0013.
- **Depends on:** M2 (product catalog, imports), M3A (sessions, roles, audit), M3B.1A
  (service-token confinement, redaction).
- **Goal:** MeoScout's backend relay can deliver approved candidates to AFFILIO over an
  authenticated, idempotent, server-to-server API with a scoped credential; AFFILIO stays the
  authority over everything that is not research data.

## Scope

1. `integration_api_keys` (identity): scoped, hashed, revocable, rotatable, expiring keys.
2. Identity kind `integration` with a route allow-list and `require_scope`.
3. Admin endpoints `/api/v1/integrations/keys` (create / list / revoke / rotate),
   `GET /api/v1/integrations/me`, CLI `affilio.scripts.create_integration_key`.
4. `POST /api/v1/products/ingest` and `GET /api/v1/products/ingest/{batch_id}`.
5. `product_ingest_batches` / `product_ingest_items`; `products.ingest_batch_id`.
6. Migration `0019_product_ingest` with downgrade; shared types; docs.

Out of scope (later phases): MeoScout relay and extension (P2/P3), NAS bridge (P4), an
admin UI for keys, a list endpoint for batches, per-field edit locks.

## Known limitations

- No per-field "edited by a person" tracking: research fields (name, seller, category,
  price, commission estimates, notes, images) are refreshed by MeoScout when they differ.
- The rate limiter is in-process (one uvicorn worker on the NAS; N workers → N × limit).
- No admin UI for keys yet (API + CLI only); no endpoint listing batches.
- The web proxy strips `Authorization`, so the relay must call the API inside the compose
  network (design §7); this milestone changes neither the proxy nor the tunnel.
- An integration key cannot read products back (`GET /products` is outside its allow-list);
  P2 only needs the per-item results, which it gets from the ingest response.
